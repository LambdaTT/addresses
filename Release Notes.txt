💬 Commentaries:

Completes the IAM permissions-domain alignment started in 0.1.6 (IAM v1.3.0): re-enables
permission enforcement using the new tag-based permissioning standard.

---

✨ Added:

    ▸ Seed `dbseeds/1795314851_addresses-permissions.php`, registering the module's permission
      tags in `IAM_PERMISSION`: `addresses.address.read` and `addresses.address.manage`.

---

🔧 Changed:

    ▸ Replaced the entity/CRUD permission codes (`ADR_ADDRESS` R/C/U/D) with tag-based
      permissions enforced via `iam/permission->requireAny()`. Read endpoints accept either
      `addresses.address.read` or `addresses.address.manage`; write endpoints require
      `addresses.address.manage`.

    ▸ Module presence is now checked via `ModsManager::modExists('iam')`, and the disabled
      `validatePermissions()` reference left behind by 0.1.6 was removed.
